# Changelog

## 0.1.0
- Drifts the colors of an EcoTech Radion profile on a Neptune Apex like passing
  clouds while a virtual outlet is ON.
- Per-color Min/Max (equal values hold a color), cloud speed 1x to 3x, and step
  time of 15 to 120 seconds.
- Settings page served through Home Assistant Ingress, or run standalone.
- Installable from GitHub as a Home Assistant add-on repository.
