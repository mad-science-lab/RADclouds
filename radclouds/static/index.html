Apex connection

Set up the Apex (once)

  1. Create the profile. In Apex Fusion, add a profile of type Radion (for example pfCloudyDay) and pick it above. Its colors and End intensity are the ones RADclouds moves. Start intensity is left alone.
  2. Create the virtual outlet. Add a virtual output (for example CloudyDay) and pick it above. Turning it ON starts the clouds; turning it OFF stops them. Give it a program or switch it by hand.
  3. Point each Radion at the profile. Add this line to the program of every Radion output that should follow the clouds, below its normal tdata lines (a later line overrides an earlier one): 
    If Output CloudyDay = ON Then pfCloudyDay
  4. Put the virtual switch where it can be turned on. Add the virtual switch to the Apex Dashboard, or add logic to control the switch's state, so the clouds actually start and stop.

Cloud range for each color

Enter a Min and a Max for every row, 0 to 100. Either Max minus Min is more than 15 so the color drifts, or Min and Max are the same and that color is held at that value and never changes.

How it runs

When the virtual outlet turns ON, the profile is set to the median of each range. Then every 60 seconds every color and the End intensity each roll 1–5 on their own (speed 1×):

Roll12345
Change

At Min or Max, a move that would go past the edge is reversed. Anywhere else, a move that would go past stops at the edge. All the new values are then written to the profile in one save.
